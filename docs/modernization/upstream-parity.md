# Перенос YAPanel 0.3.0 / 0.3.1 в Unleashed

Эталон: [0.3.0](https://github.com/dimap/yapanel-web/releases/tag/v0.3.0), commit `487a458`, и [0.3.1](https://github.com/dimap/yapanel-web/releases/tag/v0.3.1), commit `553e9b5`.

| Возможность | Реализация и проверка |
| --- | --- |
| Широкая раскладка, сворачиваемое меню, третья зона обзора, акцентный цвет, эквалайзер | Оригинальные HTML/CSS; совместимость с библиотекой и умным домом форка. Проверки раскладки, графика эквалайзера и браузера. |
| Мобильная раскладка и безопасные отступы | Оригинальный mobile.css и изменения плеера 0.3.1; тесты layout/player. |
| Сбер Звук: поток, настройки, поиск, альбомы, похожие, избранное, тексты | Оригинальные zvuk-модули и маршруты. Автотесты; реальный аккаунт сервиса для проверки здесь отсутствует. |
| Ассистент: новый интерфейс, подключения провайдеров, STT, Realtime, локальные команды | Оригинальные модули и device/assistant, регрессии Python/Go/JS. Внешние платные API и микрофон Лайт 2 на Лайт 1 не проверялись. |
| Локальный Whisper | Оригинальный отдельный Docker-профиль; установка остаётся добровольной. |
| Яндекс: очередь, альбом, похожие, избранное и плейлисты | Перенесены API и единый виджет 0.3.1. Списки Яндекса информационные; собственная библиотека остаётся кликабельной. |
| Обновление ZIP и восстановление модулей | Проверка SHA256, путей, симлинков, полноты и отката. Исходники только из релиза Chekpoinss/yandex-station-unleashed. Прямое обновление, затирающее форк оригиналом, заблокировано. До выпуска собственного архива восстановление из GitHub недоступно. |
| Приватность отчётов, резервные архивы, цвет корпуса, YAM-ссылки, восстановление анимаций | Перенесены исходники и проверки оригинала, включая ранее отсутствовавшие тесты. |
| Android | Возвращены исходники оригинала, в assets добавлены модули форка и зависимости. APK не собирался: Android SDK/устройство не использовались. |
| Windows | Собраны ZIP x64 и ARM64 с Python и собственными модулями. Физический запуск на Windows не проверен. |
| Linux / OCI | Проверены Python 3.9 и 3.14; собран локальный OCI-образ. Контейнер не публиковался. |
| Локальные MP3, SoundCloud, голосовые команды и светомузыка | Сохранён штатный audio_play/Glagol; вход в аккаунт остаётся необходим по решению владельца. Отдельный проигрыватель на колонку не добавлен. |
| Лайки | Канонический ответ сервера, синхронизация виджетов, защита повторного запроса, уведомления и сохранение SC-избранного. Проверки JS и браузерный тест SC. |
| Лайт 1 и хук | Хук установлен через существующую init.d-цепочку. Проверена настоящая перезагрузка, запуск служб и восстановление alice_speaking.led. Чужой init-файл/симлинк не перезаписывается; оригинал анимации проверяется по SHA256. |

Тестовые исправления сохраняют проверки поведения: используют настоящий процесс сцены, актуальные маршруты и блокировки конфигурации, корректный ELF-файл и реалистичный ответ preflight. Начальные 20 ошибок не скрыты отключением тестов.

Пользовательские аккаунты, медиатека и настройки не входят в патч. Публикация оформляется отдельным релизом с проверками GitHub Actions.
