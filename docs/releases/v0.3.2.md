Исправления управления музыкой и голосовых команд для локальной медиатеки.

## Изменения

- Переключение каталога Яндекс Музыки или Сбер Звука не останавливает очередь локального плеера.
- Устаревший ID облачного трека и отложенный fallback не могут заменить воспроизведение локальной медиатеки.
- Команды Алисе для паузы, продолжения, перехода к следующему или предыдущему треку, перемешивания и повтора понимают дополнительные формулировки.
- Поиск и запуск треков понимают варианты «найди», «поищи», «включи», «запусти», «поставь» и «проиграй».
- Название трека можно запускать по однозначному частичному совпадению; небольшая ошибка распознавания английского названия исправляется, неоднозначные совпадения не выбираются наугад.
- Голосовой мост показывает понятные ошибки источника вместо общей ошибки, включая случаи, когда SoundCloud блокирует поток DRM.
- Потеря события завершения голосового запроса теперь отображается в панели. Переход на внешний плеер и обнаружение чужого воспроизведения требуют повторного подтверждения.

## Обновление

Скачайте архив для своей системы из списка активов ниже. Для Windows выберите `yandex-station-unleashed-0.3.2-windows-x64.zip` или `…-windows-arm64.zip`. Для Linux используйте `yandex-station-unleashed-0.3.2.zip`. Перед обновлением сохраните пользовательские данные и настройки.

`SHA256SUMS` содержит контрольные суммы активов релиза. Ограничения источника SoundCloud, включая DRM-защиту отдельных треков, остаются на стороне сервиса.

## Проверки

- Полный локальный набор: 796 тестов пройдено, 5 пропущено на Python 3.15.
- Голосовой мост и каталог медиатеки проверены также на Python 3.9.
- Реальное распознавание голоса зависит от того, какой текст Алиса передаёт панели; DRM-защищённые потоки SoundCloud не воспроизводятся.
